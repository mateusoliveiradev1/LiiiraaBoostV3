# Fontes das artes de jogos

As capas são armazenadas localmente para que a interface instalada não dependa de rede.
Os nomes e marcas pertencem aos respectivos proprietários e são usados apenas para
identificar jogos detectados pelo usuário.

- `counter-strike-2.jpg`: arte de biblioteca pública do Counter-Strike 2 na Steam.
- `valorant.jpg`: mídia oficial publicada pela Riot Games em `cmsassets.rgpub.io`.
- `fortnite.jpg`: arte oficial distribuída pela Microsoft Store/Xbox para o Fortnite.
- `pubg.jpg`: imagem social oficial publicada em `pubg.com`.
