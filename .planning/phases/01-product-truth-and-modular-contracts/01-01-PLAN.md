## Trust Boundaries

| Boundary | Description |
|---|---|
| Registry metadata → repository | Untrusted remote package metadata is compared with the locally reviewed allowlist. |
| Dependency review → installation | Human approval is required before package code can enter the workspace. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01-01 | Spoofing | Package identity | mitigate | Require exact registry name, version, and official repository match. |
| T-01-02 | Tampering | Dependency evidence | mitigate | Regenerate deterministic report from versioned allowlist and fail on drift. |
| T-01-SC | Tampering | npm/Cargo installs | mitigate | Block installation until all `REVIEW_REQUIRED` evidence receives explicit approval. |
</threat_model>
