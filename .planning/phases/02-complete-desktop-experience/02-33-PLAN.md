## Trust Boundaries

| Boundary | Description |
|---|---|
| CurrentUser CNG store to local build | The non-exportable development key may authorize only local test artifacts. |
| CI output to evidence | Unsigned CI bytes must never masquerade as release-ready or accepted signed artifacts. |
| Build outputs to evidence record | Substituted bytes could masquerade as the reviewed artifact. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-45 | Spoofing/Tampering | development-signed package | mitigate | Thumbprint, EKU, digest, Authenticode integrity, staged bytes, and exact SHA-256 verification. |
| T-02-46 | Information disclosure | certificate custody | mitigate | CurrentUser non-exportable CNG key; non-secret identifiers only; no PFX, password, PIN, or token. |
