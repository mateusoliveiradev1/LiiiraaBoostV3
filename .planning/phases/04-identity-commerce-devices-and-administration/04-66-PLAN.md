## Trust Boundaries

| Boundary | Description |
|---|---|
| Windows inventory -> native digest collector | Raw device observations enter a non-serializable, non-logging native boundary and must be destroyed before IPC/network use. |
| Native credential/evidence custody -> API | Only authenticated account-scoped local digests and explicit confirmations cross HTTPS; React sees neither credential nor evidence. |
| API evidence protector -> PostgreSQL binding authority | Server-only keys transform validated evidence before the existing expected-version/one-PC transaction persists protected digests. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-04-66-S | Spoofing | local evidence submission | mitigate | Authenticated native client, account-bound context, minimum classes/anchor, canonical validation, and typed revalidation instead of blind trust. |
| T-04-66-T | Tampering | bind body/digest | mitigate | Server derives protected evidence and aggregate digest; client-supplied protected authority or mismatched versions are rejected. |
| T-04-66-R | Repudiation | license consumption | mitigate | Two explicit confirmations plus existing immutable audit/outbox transaction and idempotency key. |
| T-04-66-I | Information Disclosure | hardware and key material | mitigate | Raw values never serialize/log/persist; local digests stay native-to-API; wrapping keys stay server-only; React and PostgreSQL receive no raw/local identifiers. |
| T-04-66-D | Denial of Service | sparse/unsupported inventory | mitigate | Bounded collection, typed unavailable state, retry guidance, and no fabricated fallback identity. |
| T-04-66-E | Elevation of Privilege | Free/concurrent/replacement bind | mitigate | Active-Premium policy, owner authorization, expected version, partial unique index, cooldown, step-up replacement, and no silent transfer. |
</threat_model>
