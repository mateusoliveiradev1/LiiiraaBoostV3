| Live public/account/admin responses → evidence file | Browser output is untrusted until route, locale, response, semantic content, recovery, redaction, and source provenance all validate. |
| Rendered error content → durable evidence | Raw page text can contain sensitive diagnostics and must never be persisted. |

</threat_model>
