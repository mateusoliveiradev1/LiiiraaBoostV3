## Trust Boundaries
| Boundary | Description |
|---|---|
| global search/query to role-scoped records | Untrusted query state must not reveal unauthorized cases, diagnostics, targets, or audit events. |
| queue selection to contextual evidence | Selected work may expose only fields allowed by validated role and consent. |
| sensitive workflow to Phase 4 authority | Review and confirmation must terminate without real administrative effects. |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-03-75-01 | Information Disclosure | global search/evidence | mitigate | Role-first filtering, redaction, bounded queries, and denial-state tests. |
| T-03-75-02 | Elevation of Privilege | high-risk workflow | mitigate | Validated role, consent, purpose, impact, reauth preview, specific confirmation, and no-change receipt. |
| T-03-75-03 | Tampering | saved views/filters | mitigate | Closed deterministic view definitions and allowlisted URL projection. |
| T-03-75-04 | Repudiation | queue/audit context | mitigate | Immutable event identity and exact technical detail retained in audit disclosure. |
| T-03-SC | Tampering | package supply chain | accept | No package installation or dependency change. |
</threat_model>
