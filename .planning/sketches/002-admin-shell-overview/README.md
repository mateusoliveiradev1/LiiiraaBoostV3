# Sketch 002: Admin Shell + Visão geral

## Design Question

Como combinar a hierarquia calma do Calm Briefing, a navegação completa do
Mission Control e a densidade opcional do Operational Ledger sem transformar o
Admin em um dashboard SaaS genérico?

## How to View

Abra `.planning/sketches/002-admin-shell-overview/index.html` em um navegador.

## Variants

- **A: Briefing Focus** — uma prioridade operacional clara lidera; fila e
  contexto aparecem como uma leitura contínua.
- **B: Queue Canvas** — a fila domina e o briefing vira contexto compacto para
  operadores frequentes.
- **C: Balanced Deck** — prioridade, fila e saúde operacional dividem a tela em
  uma composição equilibrada.

## Selected Direction

**A: Briefing Focus** — escolhida como base do Admin Web. A fila adota a
densidade compacta de Queue Canvas nas rotas operacionais, sem alterar a
hierarquia calma da Visão geral.

## What to Look For

- Em qual variante fica mais óbvio o que precisa ser feito agora?
- Qual preserva melhor o contexto do negócio sem virar uma coleção de cards?
- Qual escala melhor entre densidade confortável e compacta?
- No modo mobile, o drawer e a lista continuam parecendo um produto próprio?
