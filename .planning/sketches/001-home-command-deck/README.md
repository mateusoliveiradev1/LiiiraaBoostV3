# Sketch 001: Home Command Deck

## Design Question

Como transformar a Visão Geral em uma estação de comando pré-jogo mais clara,
premium e autoral, preservando o dark técnico já aprovado?

## Como visualizar

Abra `.planning/sketches/001-home-command-deck/index.html`.

O refinamento visual recomendado da variante A está em
`.planning/sketches/001-home-command-deck/concept-command-deck.png`.

## Variantes

- **A: Command Deck** — próxima ação dominante, plano no centro e telemetria em
  uma rail contínua.
- **B: Session Ready** — o jogo ativo organiza a tela e as otimizações aparecem
  no contexto da sessão.
- **C: Evidence First** — usuários avançados veem primeiro comparação, origem e
  impacto esperado.

## O que observar

- Qual variante deixa a próxima ação mais óbvia sem parecer um cleaner de um
  clique?
- Onde a telemetria é mais fácil de escanear?
- Qual composição parece mais exclusiva sem depender de efeitos gamer?
- Qual variante escala melhor para as outras rotas?

## Recomendação inicial

A variante A é a base recomendada: mantém o produto acessível, reduz card soup e
oferece uma estrutura reutilizável para Otimização, Jogos e Recuperação.
