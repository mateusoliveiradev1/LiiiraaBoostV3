# Objetivo

Preparar um laboratório persistente e reproduzível no Hyper-V para validar o instalador, a inicialização, permissões, reinicialização, rollback e os primeiros planos transacionais da Fase 6 sem alterar o PC principal além do diretório dedicado do laboratório.

# Regras de segurança

- Não instalar nem usar Docker.
- Usar somente imagens oficiais da Microsoft.
- Manter a VM em uma pasta explícita fora do repositório.
- Usar o `Default Switch`; não criar bridge ou switch externo automaticamente.
- Exigir PowerShell elevado antes de qualquer alteração no Hyper-V.
- Criar VM Generation 2 com Secure Boot, TPM virtual, memória dinâmica e checkpoints explícitos.
- Nunca apresentar a VM AMD como evidência de compatibilidade Intel ou de outra GPU física.
- Preservar integralmente mudanças existentes do usuário no worktree.

# Entregas

1. Script idempotente para auditoria, criação, status, abertura e checkpoint da VM.
2. Evidência JSON de cada ação administrativa executada.
3. VM Windows 11 Enterprise Evaluation oficial pronta para instalação interativa.
4. Guia curto de uso e matriz do que pode ou não ser validado na VM.

# Verificação

- O script falha de forma clara quando não está elevado.
- O script falha sem modificar o Hyper-V quando o ISO não existe.
- A VM usa Generation 2, Secure Boot, TPM, 4 vCPUs, 8 GiB iniciais e VHDX dinâmico de 96 GiB.
- A VM não usa rede externa criada pelo projeto.
- O console pode ser aberto e checkpoints podem ser criados sem remover checkpoints anteriores.

# Estado atual

- ISO oficial baixado e SHA-256 conferido com o PDF oficial da Microsoft.
- VM criada com o hardware virtual previsto, TPM ativo e ISO anexado.
- `hvhost` e seu driver `hvservice` foram encontrados desativados no host e restaurados para inicialização Manual conforme a configuração oficial.
- Após o primeiro reboot, o driver central `Vid.sys` também foi encontrado desativado; `wvid.inf` determina `SERVICE_SYSTEM_START`.
- O driver `VMBus` também foi restaurado para Boot Start e os serviços de integração voltaram ao padrão Manual.
- VBS com Secure Boot foi habilitada sem forçar Integridade de Memória ou Credential Guard, permitindo o TPM virtual.
- A VM iniciou com sucesso e o console do Hyper-V foi aberto para a instalação interativa do Windows 11.
